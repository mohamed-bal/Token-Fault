# @tokenfault/shared

Wire contracts (types), limits, error codes and redaction helpers shared by every TokenFault package.
Platform-agnostic, no runtime dependencies. Internal building block; you normally use it through
`tokenfault`, `@tokenfault/core` or `@tokenfault/testing`.

> **Status:** pre-release (`0.x`). Not published to npm yet; build from source as described in the
> [repository README](https://github.com/mohamed-bal/Token-Fault#readme). Requires Node.js ≥ 22.12.
